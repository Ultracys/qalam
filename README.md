# Qalam Canvas

لوحة ويب عربية للكتابة الحرة بالقلم الإلكتروني، بمحرك سن قصب مسطح مبني على Canvas وPointer Events.

## التشغيل

```bash
npm install
npm run dev
```

لإنشاء نسخة إنتاجية:

```bash
npm run build
```

## البنية

- `app/`: الصفحة الرئيسية وصفحة `/diagnostics` والهوية البصرية.
- `components/`: اللوحة، شريط الأدوات، إعدادات القلم، أنماط الخط، الأدلة والتصدير.
- `lib/brushEngine.ts`: رسم الضربات كمضلعات متصلة من حواف سن مستطيل مائل.
- `lib/strokeSmoothing.ts`: تنعيم واستيفاء العينات لمنع الفراغات.
- `lib/geometry.ts`: هندسة السن وقياس المسافات.
- `lib/pointerUtils.ts`: تحويل Pointer Events إلى نقاط موحدة.
- `lib/svgExporter.ts`: تصدير كل ضربة كمضلعات SVG حقيقية.
- `store/canvasStore.ts`: سجل الضربات والإعدادات وUndo/Redo خارج مسار الرسم الحي.
- `types/`: أنواع القلم والضربات الصارمة.

## محرك القلم

كل ضربة تحفظ كنقاط مستقلة تشمل الإحداثيات والضغط والميل والوقت والسرعة. عند الرسم يحسب المحرك طرفي السن المسطح من زاويته وعرضه، ثم يربط حواف العينات المتتالية بمضلعات رباعية. يتغير العرض قليلًا حسب الضغط والميل والسرعة، وتضاف نقاط بينية على المسار لمنع التقطّع عند الحركة السريعة. أثناء الحركة تبقى الضربة في `ref` ولا تدخل المخزن إلا عند رفع القلم، لذلك لا يعتمد الأداء على إعادة تصيير React لكل نقطة.

## قيود المتصفحات

- جودة الضغط والميل تعتمد على القلم والمتصفح والتعريفات؛ بعض الأجهزة ترسل ضغطًا ثابتًا ولا ترسل الميل.
- Safari على iPad يدعم Pointer Events الحديثة، لكن سلوك اللمس ورفض راحة اليد قد يختلف حسب إصدار النظام.
- رفض راحة اليد في الويب تقريبي؛ اللوحة تتجاهل اللمس أثناء وجود قلم نشط، لكن لا توجد واجهة ويب موحدة تتحكم برفض الراحة من النظام.
- SVG يحفظ أثر السن كمضلعات متجهة، وقد يكبر حجم الملف مع الأعمال الطويلة جدًا.
- إعدادات القلم تحفظ محليًا، أما الضربات نفسها فتبقى داخل الجلسة الحالية في هذه النسخة.

## النسخة الثانية

- حفظ الأعمال واستعادتها محليًا أو من ملفات مشروع.
- تحرير الضربات بعد رسمها وتحويلها إلى منحنيات أقل عددًا.
- نماذج تدريب مرخصة لكل خط مع تقييم آلي للميل والنسب.
- معايرة ضغط وميل خاصة بكل جهاز.
- PWA وعمل دون اتصال، مع اختصارات وأقلام مفضلة.
- تحسين تصدير SVG عبر دمج المضلعات وتبسيط المسارات.
